# 철갑 전선 — 온라인 전투 게임

전차 · 전함 · 전투기가 한 전장에서 싸우는 브라우저 멀티플레이 게임입니다.
Node.js 서버(WebSocket)가 게임을 진행하고, 브라우저는 Three.js(WebGL)로 3D 화면을 그립니다.
지도는 6400 × 4800 크기이며 언덕·숲·바위가 있는 육지와 파도치는 바다로 이루어져 있습니다.

## 실행

```bash
npm install
npm start          # http://localhost:3000
```

같은 네트워크의 친구는 `http://<내 IP>:3000` 으로 접속하면 함께 싸울 수 있습니다.
포트는 `PORT=8080 npm start` 처럼 바꿀 수 있습니다.

## Render에 배포하기

저장소에 `render.yaml`이 들어 있어서 Render가 설정을 자동으로 읽습니다.

1. https://dashboard.render.com 에 GitHub 계정으로 로그인
2. **New → Blueprint** 를 누르고 이 저장소를 선택 (게임 코드가 있는 브랜치 선택)
3. **Apply** 를 누르면 빌드 후 `https://ironclad-front-xxxx.onrender.com` 같은 주소가 생김
4. 그 주소를 친구들에게 보내면 어디서든 접속 가능

Blueprint 대신 **New → Web Service** 로 직접 만들 때는 Build Command `npm install`, Start Command `npm start` 를 입력하면 됩니다.

무료 플랜은 15분 동안 접속이 없으면 서버가 잠들고, 다음 접속 때 깨어나는 데 30초~1분 정도 걸립니다.

## 전투 모드

| 모드 | 참전 기계 | 지도 |
|------|-----------|------|
| 🌐 통합전 | 전차 · 전함 · 전투기 | 대륙 + 바다 |
| 🛡 전차전 | 전차만 | 호수가 있는 육지 |
| ⚓ 해전 | 전함만 | 섬이 있는 바다 |
| ✈ 공중전 | 전투기만 | 대륙 + 바다 (상공) |

전장 인원이 10명보다 적으면 봇이 자동으로 들어와 빈자리를 채웁니다 (`MIN_COMBATANTS` 환경변수로 조절, 0이면 봇 없음).
봇은 자기 주무기로 맞출 수 있는 적을 먼저 노립니다.

## 전투 기계

| 기계 | 이동 | 주무기 (Space / J) | 보조무기 (F / K) |
|------|------|-----------------|--------------------------|
| 전차 | 육지만 | 주포 — 지상·함선 공격, 폭발 피해 | 기관총 — 공중 공격 가능 |
| 전함 | 바다만, 회전이 느림 | 함포 2연장 — 강력한 폭발 | 대공포 — 전투기 요격 |
| 전투기 | 어디든, 멈출 수 없음 | 기관포 — 정면 고정 | 유도 미사일 |

지상 포탄(주포·함포)은 전투기를 맞추지 못합니다. 전투기를 잡으려면 기관총 / 대공포 / 전투기를 쓰세요.

## 조작 (키보드만 사용, 마우스 필요 없음)

| 키 | 동작 |
|----|------|
| W / S (↑ / ↓) | 전진·후진 (전투기는 가속·감속) |
| A / D (← / →) | 선회 |
| Q / E | 포탑 왼쪽·오른쪽 회전 (전차·전함) |
| R | 포탑 정면으로 되돌리기 |
| V | 시점 전환 (뒤에서 따라가기 ↔ 위에서 내려보기) |
| Space 또는 J | 주무기 |
| F 또는 K | 보조무기 |
| Enter | 채팅 (보내기도 Enter, 취소 Esc) |
| Tab | 점수판 |
| Esc | 기체 교체 창 열기 / 닫기 |

메뉴도 키보드로 조작합니다.

- 로비: 닉네임 입력 후 Enter → 숫자키 **1~4** 로 모드 선택, Enter 로비 채팅, N 닉네임 다시 입력
- 기체 선택 창: 숫자키 **1~3** 으로 기체 선택, **L** 로비로 나가기

전투기의 무기는 기수 방향으로 고정 발사됩니다. 휴대폰처럼 키보드가 없는 기기에서는 화면 왼쪽을 끌어 이동하고 오른쪽을 눌러 주무기를 쏩니다.

## 채팅

- 로비 채팅: 모드를 고르기 전 로비에 있는 사람끼리 대화
- 전장 채팅: 같은 모드(방)에 있는 사람끼리 대화, 입장/퇴장 알림 포함

## 구조

- `server.js` — HTTP 정적 파일 + WebSocket, 30틱/초 서버 권위 시뮬레이션, 봇 AI
- `public/shared.js` — 서버와 클라이언트가 함께 쓰는 능력치 / 지도 생성 규칙
- `public/client.js` — 입력, 상태 보간, HUD, 미니맵, 채팅
- `public/world3d.js` — 3D 렌더링: 지형·바다·하늘, 전투 기계 모델, 탄환, 폭발·연기·물보라 파티클, 추적 카메라
